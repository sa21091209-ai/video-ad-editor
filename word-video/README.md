# فيديو «كلمة ومعنى» / «كلمة وقصة»

قالب ريموشن عمودي 1080×1920: الكلمة تطلع كبيرة بخط الرقعة، تصعد فوق، وبعدها المعنى أو القصة سطر سطر، ثم شاهد (اختياري) وخاتمة.

## كلمة جديدة

عدّل `src/data.ts` (الكلمة، السطر تحتها، الأسطر، الشاهد، الخاتمة). مدة الفيديو تنحسب لحالها من عدد الأسطر.

- `mode: 'meaning'` ← كلمة ومعنى
- `mode: 'story'` ← كلمة وقصة
- `example: ''` ← بلا شاهد

## التعليق الصوتي

حط ملفات الصوت في مجلد داخل `public` (مثل `public/voice/asas`) واكتب اسمه في `voice`.
الملفات بالترتيب: `l01` العنوان، `l02` الكلمة، `l03` السطر تحتها، ثم ملف لكل سطر، ثم الشاهد (إن وُجد)، ثم الخاتمة.
كل جملة تطلع على الشاشة مع نطقها، والتوقيت ينحسب لحاله من طول كل ملف. `voice: ''` ← بلا صوت.

## تشغيل

```
npm install
npm run studio                                   # معاينة
npx remotion render WordVideo out/word.mp4       # كلمة ومعنى
npx remotion render WordStory out/story.mp4      # كلمة وقصة
```

الخطوط من `video-ad-editor/motion/fonts` (رخصها في `LICENSES.txt` هناك).
