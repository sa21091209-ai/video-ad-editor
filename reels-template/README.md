# قالب ريلز البودكاست (HyperFrames)

نموذج تصميم لريل 9:16 من حلقة بودكاست: هوك بكلمات تنضرب، شارة القناة طول الريل، عنوان الموضوع، كابشن كلمة بكلمة، بطاقة موشن (آية)، كرت نهاية بالمصدر.

- قاعدة الحقوق: اسم البودكاست والقناة ظاهر طول الريل، وكرت النهاية فيه المصدر والضيف والمقدّم. بدون أي روابط.
- `#speaker` فيه لقطة مؤقتة. بالريل الحقيقي يتبدّل بـ `<video>` مقصوص 9:16 من الحلقة، والكابشن من تفريغ كلام الضيف.
- المؤثرات الصوتية: `python3 tools/sfx.py sfx.wav`
- التصدير: `npx hyperframes render -o out.mp4`
